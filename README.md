# Arc Launcher

Downloads and updates for **Arc Launcher**, the Dungeon Blitz launcher with a built-in damage meter and character transfer to Dungeon Blitz Revamp.

**[Download the latest version](https://github.com/kagarisa/arc-launcher-releases/releases/latest)**: run `Arc-Launcher-Setup-x.y.z.exe`. It installs for your Windows user only, with no administrator rights needed. Windows may warn that the installer is from an unknown publisher because it isn't code-signed; choose *More info*, then *Run anyway*.

Once installed, Arc Launcher updates itself from this page: it checks a few seconds after it starts and every hour after that, downloads a new version in the background, and offers **Restart and update**.

This repository holds releases only.
